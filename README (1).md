# Terminkalender

Eine Wochenagenda im Look eines Papierkalenders: eine Woche auf zwei Seiten, Tage als senkrechte Spalten, Samstag und Sonntag teilen sich eine Spalte.

**Funktionen**

- Notizen pro Tag, direkt auf die gewünschte Zeile klicken
- To-do-Liste pro Spalte mit Kästchen zum Abhaken
- Wochen blättern, Sprung zu „Heute“, Kalenderwoche
- Volltextsuche über alle Wochen
- Drucken (A4 quer) und Dunkelmodus
- „Als Datei speichern“: komplette App als einzelne HTML-Datei sichern

## Benutzen

### Variante 1: Direkt im Browser (am einfachsten)

Die GitHub-Pages-Seite öffnen und loslegen. Mit einem Lesezeichen ist die Agenda jederzeit wieder da. Es ist keine Installation und kein Konto nötig.

### Variante 2: Als Datei auf dem eigenen PC

1. In der Agenda oben auf **„Als Datei speichern“** klicken. Je nach Browser öffnet sich „Speichern unter“, sonst landet die Datei im Download-Ordner.
2. Alternativ hier auf GitHub die Datei `index.html` öffnen und oben rechts auf das Download-Symbol („Download raw file“) klicken. Oder im Repository auf **Code → Download ZIP** klicken und die ZIP-Datei entpacken.
3. Die Datei `index.html` per Doppelklick im Browser öffnen. Sie funktioniert auch ohne Internet, nur die Schriftart wird dann durch eine Standardschrift ersetzt.

## Hinweise zu den Einträgen

- Alle Einträge werden ausschließlich im Browser des jeweiligen Nutzers gespeichert (localStorage). Es gibt keinen Server und keine Übertragung von Daten.
- Die Einträge der Webseite und die einer lokal geöffneten Datei sind getrennt. Eine lokal geöffnete Datei startet mit einem leeren Kalender.
- Beim Löschen der Browserdaten oder im Privatmodus gehen die Einträge verloren.
- Zum Sichern oder Umziehen auf einen anderen PC dient „Als Datei speichern“: Die gespeicherte Datei enthält die Einträge mit. Diese Datei sollte man nicht weitergeben oder öffentlich hochladen, wenn persönliche Termine darin stehen.
