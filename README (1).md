# Terminkalender

Eine Wochenagenda im Look eines Papierkalenders: eine Woche auf zwei Seiten, Tage als senkrechte Spalten, Samstag und Sonntag teilen sich eine Spalte.

**Funktionen**

- Notizen pro Tag, direkt auf die gewünschte Zeile klicken
- To-do-Liste pro Spalte mit Kästchen zum Abhaken
- Wochen blättern, Sprung zu „Heute“, Kalenderwoche
- Volltextsuche über alle Wochen
- Drucken (A4 quer) und Dunkelmodus
- „Als Datei speichern“: komplette App als einzelne HTML-Datei sichern

**Benutzen:** Die Datei `index.html` im Browser öffnen oder die GitHub-Pages-Seite aufrufen.

**Datenschutz:** Alle Einträge werden ausschließlich im Browser des jeweiligen Nutzers gespeichert (localStorage). Es gibt keinen Server und keine Übertragung von Daten.
